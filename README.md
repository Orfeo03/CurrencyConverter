 Currency Converter

A simple currency converter application built with **Python** that allows users to convert money between different currencies using real-time exchange rates from an API.

This project was created to practice working with Python, APIs, JSON data, and currency conversion calculations.

 Features

-  Convert between different currencies
-  Support for popular currencies such as EUR, USD, GBP, and ALL
-  Retrieve the latest available exchange rates using an API
-  Calculate converted amounts automatically
-  Simple and beginner-friendly Python project

 Technologies Used

- Python– Main programming language
- Requests– Fetch exchange rates from an API
- REST API – Retrieve currency exchange data


 Installation

1. Clone the repository


git clone https://github.com/Orfeo03/CurrencyConverter.git


2. Navigate to the project folder

cd CurrencyConverter

3. Install the required library


pip install requests

**4. Run the application**


python main.py


Replace `main.py` with the actual name of your Python file if it is different.*
